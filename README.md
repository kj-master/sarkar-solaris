# Sarkar Solaris Fragrance

I am creating a new signature fragrance under the existing Sarkar Perfume brand for a university assignment.

IMPORTANT: The existing Sarkar Perfume brand identity and packaging must NOT be redesigned.

I want to introduce a new fragrance called:

SARKAR SOLARIS

Fragrance concept:

Top impression: bright bergamot, fresh mandarin and saffron

Heart: warm vanilla, amber and subtle warm spices

Base: creamy sandalwood, cedarwood and soft musk

Overall character: radiant + warm + golden + woody + sophisticated

Long-lasting fragrance

The fragrance should feel sophisticated, modern and masculine rather than overly sweet or feminine.

ONE-LINE BRAND STORY:
"Bright citrus and saffron meet warm vanilla, golden amber and polished woods, creating a radiant expression of power that stays with you."

VERY IMPORTANT PACKAGING INSTRUCTIONS:
Use the existing Sarkar Perfume bottle from the reference website as the exact visual reference.

DO NOT:

redesign the bottle

change the bottle silhouette

change the bottle proportions

change the cap shape

change the bottle structure

create a different bottle style

make it a round, square, rectangular or luxury-style bottle

add decorative elements to the bottle

redesign the Sarkar logo

change the existing packaging layout

The new fragrance should look like it is simply ANOTHER FRAGRANCE VARIANT in the existing Sarkar range.

The ONLY visual difference should be the fragrance variant/name and a VERY SUBTLE WARM GOLDEN/AMBER TINT representing the radiant, sunlit character of Solaris.

The bottle shape, cap, proportions and overall packaging language must remain visually identical to the existing Sarkar product.

If an existing Sarkar product image is available, use it as the reference and preserve its geometry rather than generating a new bottle design.

Do not invent a new packaging design.

For now, focus only on establishing the new product correctly within the existing Sarkar brand system. Do not build the complete landing page yet.
